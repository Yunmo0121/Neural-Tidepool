Lab 1 question

How does a neuron turn an input current into spikes, and what limits how fast it can fire?

  1. Model

    A leaky integrate-and-fire neuron, τ dV/dt = Vrest − V + RI. When V reaches θ it spikes, resets to Vreset and pauses for tref.

  2. Experiment

    Inject a current with the Stimulus controls and record the membrane voltage on the oscilloscope. The protocols give step-by-step procedures.

  3. Observation

    Watch the voltage relax towards V∞ = Vrest + RI, cross θ and reset, and see how the firing rate changes with the current.

  4. Explanation

    Each protocol ends with an explanation, and the Methods page gives every equation and definition.

      Recorded runs stay on the oscilloscope as overlays, so you can compare conditions. Each run keeps its full setup and can be restored or saved as an experiment file.

      Leaky integrate-and-fire neuron, integrated exactly between events (forward Euler available for comparison). Input current is held constant within each time step. The glow timing comes from simulated spikes; the pulse moving along the axon is a conceptual illustration, since a single-compartment model has no spatial propagation.
