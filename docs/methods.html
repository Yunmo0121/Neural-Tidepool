Model

The lab simulates a single leaky integrate-and-fire (LIF) neuron driven by an injected current \(I(t)\). Below threshold the membrane potential obeys

$$\tau_m \frac{dV}{dt} = V_{\mathrm{rest}} - V + R\,I(t),$$

where \(\tau_m\) is the membrane time constant and \(R\) the membrane resistance. With time in ms, resistance in MΩ and current in nA, the product \(RI\) is in mV.

When \(V\) reaches the threshold \(\theta\) at time \(t^{*}\), a spike is recorded at \(t^{*}\), the potential is reset to \(V_{\mathrm{reset}}\), and it is held there for the absolute refractory period \(t_{\mathrm{ref}}\). Integration resumes at \(t^{*} + t_{\mathrm{ref}}\). The spike is an event; the model does not describe the shape of the action potential.

The parameters must satisfy \(\tau_m > 0\), \(R > 0\), \(t_{\mathrm{ref}} \ge 0\) and \(\theta > \max(V_{\mathrm{rest}}, V_{\mathrm{reset}})\); the lab refuses settings that break these conditions.

Numerical method

Time grid and input

Results are reported on the grid \(t_k = k\,\Delta t\), \(k = 0, 1, \dots, n-1\), with \(n = \lceil (T + \Delta t/2)/\Delta t \rceil\) for a recording of length \(T\). The input is held constant within each step (zero-order hold): on \([t_{k-1}, t_k)\) the current is \(I_{k-1} = I(t_{k-1})\). The simulation starts at rest, \(V(0) = V_{\mathrm{rest}}\).

Exact integrator (default)

For a constant current the equation is linear and has the closed-form solution

$$V(t+h) = V_\infty + \big(V(t) - V_\infty\big)\,e^{-h/\tau_m}, \qquad V_\infty = V_{\mathrm{rest}} + R\,I.$$

If \(V_\infty > \theta\) and the update reaches the threshold, the crossing time is found exactly:

$$t^{*} = t + \tau_m \ln\frac{V(t) - V_\infty}{\theta - V_\infty}.$$

For an input that is piecewise constant on the grid, the only error of this method is floating-point rounding. The Analysis panel measures it at around \(10^{-13}\) ms.

Forward Euler (for comparison)

The Euler update is \(V(t+h) = V(t) + (h/\tau_m)\,(V_\infty - V(t))\). When it crosses threshold, the crossing time is found by linear interpolation, \(t^{*} = t + h\,(\theta - V(t))/(V(t+h) - V(t))\). Its error in spike times is proportional to \(\Delta t\).

Events inside a step

Spikes and the end of a refractory period can fall anywhere inside a step. The engine processes each step as a sequence of sub-intervals: it consumes any remaining refractory time, integrates from \(V_{\mathrm{reset}}\) from the exact moment the refractory period ends, and, after a spike at \(t^{*}\), continues from \(t^{*}\) with the rest of the step. Spike times and refractory periods are therefore never rounded to the grid. The stored trace \(V_k\) is the true membrane state at \(t_k\); it never exceeds \(\theta\).

Two independent implementations

The algorithm is implemented in JavaScript for the browser (docs/js/lif.js) and in Python (neuron.py). An automated test runs every waveform with both integrators, two time steps and two refractory periods in both languages and requires the traces and spike times to agree to within \(10^{-9}\).

Stimuli

All currents are in nA and times in ms. \(H\) is the unit step and \(\mathbf{1}\) the indicator of an interval.

WaveformCurrentParameters

Step\(I(t) = A\,H(t - t_0)\)amplitude, start \(t_0\)
Pulse\(I(t) = A\,\mathbf{1}[t_0 \le t < t_0 + w]\)amplitude, start, width \(w\)
Two pulses\(A\,\mathbf{1}[t_0 \le t < t_0 + w] + A\,\mathbf{1}[t_0 + g \le t < t_0 + g + w]\)amplitude, start, width, gap \(g\) (start to start); overlapping pulses do not add
Sine\(I(t) = I_0 + A \sin(2\pi f t / 1000)\)offset \(I_0\), swing \(A\), frequency \(f\) in Hz
Noisy\(I(t) = \mu + \sigma\,\eta(t)\)mean \(\mu\), noise size \(\sigma\), seed

The noise \(\eta\) is an Ornstein–Uhlenbeck process with zero mean, unit variance and correlation time \(\tau_\eta = 5\) ms. It is sampled with the exact update

$$\eta_k = a\,\eta_{k-1} + \sqrt{1 - a^2}\;\xi_k, \qquad a = e^{-\Delta t/\tau_\eta}, \qquad \xi_k \sim \mathcal{N}(0, 1),$$

starting from the stationary distribution, \(\eta_0 \sim \mathcal{N}(0,1)\). Its statistics therefore do not depend on \(\Delta t\). Normal deviates come from the Box–Muller transform applied to the 32-bit mulberry32 generator, seeded with the integer seed. The Python engine contains a bit-for-bit copy of this generator, so a seed gives the same current in both languages.

Exact results used for validation

For a constant current above the rheobase, starting from rest, the first spike occurs at

$$t_1 = \tau_m \ln\frac{RI}{RI - (\theta - V_{\mathrm{rest}})},$$

and the steady firing rate (the f–I curve) is

$$f(I) = \left[\,t_{\mathrm{ref}} + \tau_m \ln\frac{RI + V_{\mathrm{rest}} - V_{\mathrm{reset}}}{RI + V_{\mathrm{rest}} - \theta}\right]^{-1}, \qquad I > I_{\mathrm{rh}}.$$

The f–I panel plots the ISI rate of 2 s simulations at 41 currents against this formula; a current with no spikes has a measured rate of 0, and one that gives a single spike in 2 s has no measurable rate and is omitted. The time-step panel measures \(|t_1^{\mathrm{sim}} - t_1|\) for \(\Delta t \in \{1, 0.5, 0.2, 0.1, 0.05, 0.02, 0.01\}\) ms and both integrators, and fits the slope of \(\log_{10}\) error against \(\log_{10}\Delta t\) for Euler by least squares.

Reproducibility

Every recorded run is stored as an experiment file (JSON) with these fields:

FieldContent
format, schemaVersionneural-tidepool-experiment, version 1
engineVersionVersion of the simulation engine that produced the results
labsingle-neuron
setup.waveform, setup.stimulusWaveform name and every stimulus parameter, including the seed
setup.membraneAll membrane parameters, dtMs and method
setup.durationMsRecording length
resultsSpike times and the summary readouts

Restoring a run in the lab, or running python reproduce.py file.json, regenerates the stimulus, re-runs the simulation and compares the spike times with the record. With the same engine version they agree to within \(10^{-9}\) ms. Results from a different engine version may differ, and the lab says so.

Limitations

  • A single compartment: there is no dendritic or axonal geometry, so signals do not propagate in space. The pulse travelling along the axon in the animation is a conceptual illustration timed to the spikes.
  • Spikes are events: the action-potential waveform, ion channels and the relative refractory period are not modelled.
  • No adaptation: after each reset the neuron forgets its history, so it cannot reproduce adaptation, bursting or rebound firing.
  • Parameters are fixed during a run, and the input is piecewise constant on the output grid.
  • The noise is a coloured Gaussian current, not a model of individual synaptic inputs.
