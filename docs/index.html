How the labs are made

From the equations

Every lab opens with the model it simulates, written out in full, so what moves on screen can be traced back to a line of mathematics.

Exact, and checked twice

Lab 1 solves its equation exactly between spikes. The same algorithm is written independently in JavaScript and Python, and tests require the two to agree.

Reproducible

Every recorded run keeps its full setup, random seed and engine version, so it can be restored in the browser or re-run in Python.

The model, numerical method and every definition are written up in the Methods.
